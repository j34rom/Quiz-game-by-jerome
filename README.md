# Quiz-game-by-jerome
A terminal-based Python quiz game covering basic computer concepts, built with reusable functions and case-insensitive answer checking. Created as a learning project — open source for everyone who wants to build their own mini console projects.

## Run
```
python3 my_quiz_game_ver.1.2.py
```
`My_first_quiz_game_project_outdated.py` is the original case-sensitive version, kept for history only.
